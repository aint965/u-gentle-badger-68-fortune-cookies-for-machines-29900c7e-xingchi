An entry for the [Fortune Cookies for Machines](https://make.fun/bounty/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e) competition on make.fun.

## What it does

`main.ts` writes a single fortune-cookie line — one an AI agent would crack open — to `/output/entry.txt`. The line is fixed and deterministic: the same bytes on every run.

## Run it

```sh
node main.ts
```

It creates `/output` if needed and writes the fortune to `/output/entry.txt`.
